How to read this workbench

A / Price. P50 is the predicted monthly import unit value in GBP/kg, not a pure titanium spot price. P05-P95 describes an estimated 90% interval, not guaranteed coverage. Product mix and low volumes can affect unit values.

B / Supplier shift. Four probabilities describe future changes in the country's UK supply share by weight. The largest probability is the predicted class, not a guaranteed chance of being correct for this case. Calibration limitations remain visible.

C / Freight. The freight producer-price index is a broad transport proxy, not a UK titanium shipping quote. The model predicts log change and converts it to an index level. Brent oil is a model input, not a separately predicted target.

H3 and H6 are the main horizons. H12 is reporting-only for A/C and unsupported in this selected B package. Results cannot be added together: GBP/kg, probabilities and index points are different quantities. Saved model selection is preserved; no tuning uses these UI requests.
