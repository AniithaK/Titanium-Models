What changed

Added supplier-share lag levels, rolling means and volatility, cross-supplier rank, momentum acceleration and current market-level features. Tested tuned classifiers, continuous share-change regressors and a validation-selected soft-voting ensemble.

Integrity rule: selection uses only the 2018-June 2021 validation period. Disruption and post-disruption observations are not used to choose the model. Accuracy is not inflated by changing class thresholds or using future features.
