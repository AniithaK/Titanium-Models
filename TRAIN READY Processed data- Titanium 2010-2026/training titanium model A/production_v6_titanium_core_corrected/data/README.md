# Training Data

This folder contains the unchanged 396-row, 134-column titanium-core snapshot
used by V6. It covers January 2010 through June 2026 for HS 810820 and HS
810890 and excludes all USGS and World Bank features.

V6 preserves V5's validation-only, acceptance-aligned model selection and fixes
evaluation calibration so the selected model and the no-change baseline each
use their own pre-test residual history.
