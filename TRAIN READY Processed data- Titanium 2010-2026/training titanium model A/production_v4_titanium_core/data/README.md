# Training Data

`titanium_model_a_production_v4_titanium_core_training.csv` is the isolated
396-row, 134-column snapshot used for this run. It covers January 2010 through
June 2026 for HS 810820 and HS 810890.

The file excludes every USGS and World Bank feature. The 41 model inputs are
derived from UK titanium import history, supplier structure, Bank of England
FX, ERUC/PPI, seasonality and observation-quality indicators.
