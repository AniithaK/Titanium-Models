Executive view

What the evidence supports

These models cannot be ranked against each other because they predict different targets.

Model A: demo-ready research model

All six selected validation configurations meet their interval gates. The 2022-2023 H3/H6 stress tests also pass. Post-disruption performance is mixed, especially for H12 where incomplete future targets reduce coverage.

Model B: useful directional demo

Validation and test Brier scores beat both baselines, showing useful probability information. Exact probabilities need recalibration because worst-bin gaps exceed 0.10 in validation and post-disruption evaluation. H12 remains reporting-only.
