## Start The Local App

Use Python 3.11 or newer compatible with the pinned packages (Python 3.12 recommended for a new environment). From this root, install `python -m pip install -r requirements.txt`. Exact direct dependency versions match the verified local environment; a clean installation has not yet been tested. Each selected package also has its own pinned requirements.

Run `Combined Models A B C Prediction UI/START_UI.cmd`, then open http://127.0.0.1:8765. Stop with Ctrl+C. Predictions execute saved models; no training happens through the UI.

Verification: from the UI directory, run `python -m unittest test_app -v`. The copied app reproduces 118 reference values. Copies are research/demo packages, not a claim of production approval. B probability calibration gaps, C fallback/acceptance gaps and assumed publication dates remain unchanged. A/B data references June 2026 and C August 2026; copying does not update the data date.
